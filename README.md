## The entry

> I clicked 'I'm not a robot', but for you, I'd fail the test on purpose.

One single-line joke pickup line aimed at a robot — the CAPTCHA test itself becomes the flirt: passing the "I'm not a robot" check proves you're human, but for this one you'd fail it on purpose.

## Run

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It first checks the shipped `entry.txt` matches the entry, then applies the bounty gate: 1–200 characters, not whitespace only, exactly one line.
